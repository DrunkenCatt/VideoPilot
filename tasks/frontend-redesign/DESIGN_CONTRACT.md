# VideoPilot 前端设计合同

> 版本：F0 v1
>
> 冻结日期：2026-11-15
>
> 依据：现有 Vue 功能、项目 Roadmap、用户提供的概念图及 2026-11-15 对整体计划的执行确认。

## 1. 产品体验目标

界面应像真实、克制的桌面 SaaS，而不是宣传页或 AI 概念图。视觉服务于长视频阅读、解析状态判断和证据核验：

- 米白画布、白色内容面、浅灰分区和蓝色主操作。
- 主要层级依靠排版、留白和细边框，不依靠大面积渐变与重阴影。
- 玻璃效果只允许出现在侧栏、顶层弹框和移动抽屉，且必须保证文字对比度。
- 业务状态同时使用文字或图标表达，不只依赖红绿颜色。
- 页面使用真实业务术语与真实状态，不展示概念图中的假百分比、假课程或假统计。

## 2. 页面和路由合同

| 导航 | 路由 | 当前 Job 必需 | 主操作 | 空状态下一步 |
| --- | --- | --- | --- | --- |
| 视频工作台 | `/workspace/:jobId?` | 是 | 播放、定位内容片段、进入问答 | 打开切换视频或媒体资料库 |
| 媒体资料库 | `/library` | 否 | 上传、选择媒体、创建解析任务 | 上传第一条视频 |
| 解析任务 | `/analysis`、`/analysis/:jobId` | 详情页是 | 查看进度、取消、Replay、打开工作台 | 前往资料库创建任务 |
| 视频上下文 | `/context/:jobId?` | 是 | 阅读 ASR/OCR/关键帧并跳转时间 | 选择已就绪视频 |
| 证据问答 | `/answers/:jobId?` | 是 | 提问、阅读引用、跳转证据 | 选择已就绪视频 |
| 评测中心 | `/evaluation` | 否 | 运行和查看既有评测能力 | 按既有评测合同引导 |
| 系统设置 | `/settings` | 否 | 界面偏好、只读信息、退出 | 不适用 |

约束：

- 不创建 `/answer-history` 或其他跨视频问答聚合路由。
- `jobId` 是工作台、上下文、问答三个页面的唯一共享业务上下文。
- 解析任务详情允许打开非 `READY` Job；工作台、上下文和问答根据 Job 状态禁用不可用能力。
- 路由中的 Job 无权限、已删除或格式错误时，显示可恢复错误并清除对应本地最近项，禁止回显旧页面数据。

## 3. 导航和上下文合同

### 3.1 侧栏

```text
┌────────────────────────┐
│ VideoPilot             │
│ Evidence Studio        │
├────────────────────────┤
│ 视频工作台             │
│ 媒体资料库             │
│ 解析任务               │
│ 视频上下文             │
│ 证据问答               │
├────────────────────────┤
│ 评测中心               │
│ 系统设置               │
│                        │
│ 存储空间（真实数据）   │
├────────────────────────┤
│ 账户 / 登录 / 退出     │
└────────────────────────┘
```

- 当前页面使用蓝色文字、浅蓝背景和左侧/末端标记共同表达。
- 视频工作台、视频上下文、证据问答在没有当前 Job 时仍可进入，但必须显示选择视频空状态。
- Agent 不作为一级导航；实验能力只存在于证据问答内部并受既有开关控制。

### 3.2 顶栏

- 左侧：面包屑和页面标题，不重复侧栏品牌。
- 右侧：`切换视频`、必要的通知/状态入口、账户操作。
- `切换视频` 是上下文选择器，不叫“问答历史”或“打开最近视频”。
- 当前 Job 存在时，显示视频名、解析目标或版本和状态；文件名过长时截断但提供完整可访问名称。

### 3.3 切换视频弹框

每个列表项必须包含：

- 视频原始文件名。
- 最近 Job 的目标、模式或可区分版本。
- `READY`、运行中、失败等明确状态。
- 更新时间；若未来实现“最近打开”，再显示打开时间。

同一 Media 的多个 Job 按 Media 分组；默认动作打开最近 `READY` Job，其他 Job 可展开选择。Media 已上传但没有 Job 时提供“创建解析任务”，不能显示为可问答。

## 4. 页面状态矩阵

| 页面 | Loading | Empty | Error | Retryable | Disabled/受限 |
| --- | --- | --- | --- | --- | --- |
| 应用壳层 | Session 校验占位 | 不适用 | Session 服务不可用 | 重新校验 | 未登录时底层不可操作 |
| 媒体资料库 | 列表骨架、上传进度 | 尚未上传视频 | 列表/上传失败 | 重新加载或重试上传 | 探测未完成时不可创建 Job |
| 解析任务 | 列表/详情骨架 | 尚无任务 | SSE/详情失败 | SSE 重连、重新加载 | 终态任务不可取消 |
| 视频工作台 | Job/Media/Context 分区骨架 | 未选择视频 | 当前工作区不可读取 | 重新加载或重新选择 | Job 未 READY 时问答禁用 |
| 视频上下文 | 播放器和 Segment 骨架 | Context 无 Segment | 上下文/临时链接失败 | 续期、重新加载 | 降级通道明确标记 |
| 证据问答 | 历史骨架、提交中 | 尚无问答 | 请求、预算或模型失败 | 按错误分类允许重试 | 非 READY、开关关闭或权限不足 |
| 评测中心 | 沿用现有状态 | 沿用现有状态 | 沿用现有状态 | 沿用现有状态 | 冻结数据和运行规则不变 |
| 系统设置 | 最小占位 | 不适用 | 偏好保存失败 | 重试本地保存 | 服务端密钥与硬门只读/不展示 |

所有状态必须保留布局上下文和明确下一步；禁止只显示空白、无限 Spinner 或通用“出错了”。

排版：

- 标题：`Avenir Next`、`Noto Sans SC`、`Microsoft YaHei`、无衬线回退。

- 页面背景不使用彩色渐变。
- 常规卡片不使用阴影，仅使用 1px 边框和层级色。
- 弹框、Popover 和移动抽屉可以使用 `--shadow-popover`。
- 控件、卡片、弹框使用分级圆角，禁止所有元素统一为超大圆角胶囊。
- 主按钮为蓝底白字；次按钮为白底边框；危险操作保持独立危险色并要求确认。

## 6. 响应式线框

### 6.1 桌面（1024px 以上）

```text
┌──────────────┬──────────────────────────────────────────────┐
│ 固定侧栏     │ 顶栏：面包屑                  切换视频 账户 │
│ 224-248px    ├──────────────────────────────────────────────┤
│              │ 页面标题 / 说明                             │
│ 导航         │                                              │
│              │ 主要内容区                                   │
│              │ 主列优先，辅助列不超过约 36%                 │
│ 存储/账户    │                                              │
└──────────────┴──────────────────────────────────────────────┘
```

- 主内容最大阅读宽度约 1440px，超宽屏保留稳定边距。
- 工作台优先保证播放器宽度；右侧内容列表可独立滚动，但不产生嵌套横向滚动。

### 6.2 平板（768-1023px）

```text
┌──────┬──────────────────────────────┐
│ 图标 │ 顶栏 / 切换视频             │
│ 导航 ├──────────────────────────────┤
│ 72px │ 主内容单列或 2:1 窄分栏     │
└──────┴──────────────────────────────┘
```

- 侧栏折叠为带可访问名称的图标栏；聚焦或触发后可展开。
- 工作台辅助列在空间不足时落到播放器下方。

### 6.3 手机（320-767px）

```text
┌─────────────────────────────┐
│ 菜单  页面标题   切换视频   │
├─────────────────────────────┤
│ 主内容单列                  │
│                             │
│ 弹框使用接近全屏的底部面板 │
└─────────────────────────────┘
```

- 侧栏为模态抽屉，打开后圈定焦点并阻止底层操作。
- 表格转为分组列表，不通过压缩字体强塞桌面表格。
- 操作按钮点击目标不小于 44×44 CSS px。

## 7. 关键交互合同

### 7.1 登录弹框

- Session 校验确认未登录后自动打开。
- 初始焦点落到用户名；Tab 被限制在弹框中。
- 提交中防重复提交；错误信息使用 `role="alert"`。
- 未登录时不请求 owner 业务数据，底层内容不可点击或被辅助技术聚焦。
- Session 过期时保留目标路由，重新登录成功后恢复。

### 7.2 引用跳转

- 点击引用切换/保持到同一 `jobId` 的视频上下文并定位时间。
- 如果播放器访问链接过期，先续期再定位。
- 引用无法定位时保留答案并显示具体错误，不跳到其他视频。

### 7.3 危险操作

- 取消与 Replay 不能只靠图标表达。
- Replay 显示影响范围和原因输入，确认按钮使用明确动词。
- 禁止把取消、删除或 Replay 放在无确认的一键主操作位置。

## 8. 运行配置边界

2026-11-15 只读检查本地 `.env` 后确认：

- 文件包含运行所需凭据，但这些值未复制到本合同或 Git。
- 实际 `.env` 未声明 Agent、Agent Worker、自动目标分析及其 Vite 开关。
- Compose 与后端对三个 Agent 开关的缺省值均为 `false`。
- 前端仅在对应 `VITE_*` 值严格等于 `true` 时显示能力，因此缺省关闭。

F1-F12 不得以 UI 重构为由改变这些默认值，也不得把 `.env`、密码、Token 或 API Key 加入提交。

## 9. 明确拒绝的实现

- 用第一页媒体大小相加展示“总存储用量”。
- 用视频播放时长推断“学习完成率”并宣称已持久化。
- 把 `VideoSegment` 改名为课程章节而没有 Chapter 合同。
- 仅在前端过滤 owner 数据而放松后端权限校验。
- 为不同页面各维护一份当前 Job 状态。
- 因概念图需要而增加假数据、硬编码任务、伪 SSE 或本地状态机。
- 在设置页展示或编辑模型密钥、Prompt 原文、模型原始响应或质量硬门。
